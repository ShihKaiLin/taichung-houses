# Google Sheets 自動化資料庫設定指南

## 步驟一：建立 Google 試算表

1. 前往 [Google Sheets](https://sheets.google.com)
2. 點擊「空白」建立新試算表
3. 將試算表命名為「台中房地產資料庫」

---

## 步驟二：安裝 Google Apps Script

### 2.1 開啟 Apps Script 編輯器

1. 在試算表中，點擊上方選單：**擴充功能** → **Apps Script**
2. 會開啟新視窗（Apps Script 編輯器）

### 2.2 貼上腳本代碼

1. 刪除預設的 `function myFunction() {}` 代碼
2. 將 `google-apps-script/Code.gs` 的完整內容複製貼上
3. 點擊上方的「儲存」圖示（💾）

### 2.3 設定 Google Maps API Key

#### 取得 API Key

1. 前往 [Google Cloud Console](https://console.cloud.google.com)
2. 建立新專案或選擇現有專案
3. 啟用 **Geocoding API**：
   - 左側選單 → API 和服務 → 程式庫
   - 搜尋「Geocoding API」
   - 點擊「啟用」
4. 建立憑證：
   - 左側選單 → API 和服務 → 憑證
   - 點擊「建立憑證」→ API 金鑰
   - 複製產生的 API Key

#### 設定 API Key

在 Apps Script 代碼中，找到第 16 行：

```javascript
MAPS_API_KEY: 'YOUR_GOOGLE_MAPS_API_KEY',
```

將 `YOUR_GOOGLE_MAPS_API_KEY` 替換為您的 API Key：

```javascript
MAPS_API_KEY: 'AIzaSyAbc123...您的API Key',
```

---

## 步驟三：初始化試算表

### 3.1 執行初始化函數

1. 在 Apps Script 編輯器中，點擊上方的「執行」按鈕
2. 選擇函數：`initializeSheet`
3. 第一次執行時會要求授權：
   - 點擊「檢查權限」
   - 選擇您的 Google 帳戶
   - 點擊「進階」→「前往『專案名稱』（不安全）」
   - 點擊「允許」

4. 執行完成後，回到試算表，會看到：
   - 第一列已自動填入欄位標題
   - 標題列有深藍色背景
   - 欄位寬度已自動調整

### 3.2 試算表欄位說明

## 步驟四：使用自動爬蟲功能

### 4.1 新增物件資料

1. 在試算表的第 2 列（或任何空白列）
2. 在 **A 欄（網址）** 貼上物件網址，例如：
   ```
   https://sale.591.com.tw/home/house/detail/2/12345.html
   ```
3. 按下 Enter 鍵
4. 腳本會自動：
   - 爬取案名、地址、價格、圖片
   - 提取行政區
   - 計算經緯度
   - 設定狀態為「上架」
   - 記錄更新時間

### 4.2 支援的網站

- ✅ **591 房屋交易網**：`sale.591.com.tw`
- ✅ **樂屋網**：`rakuya.com.tw`
- ✅ **永義房屋**：`etwarm.com.tw`
- ✅ **好房網**：`housefun.com.tw`

### 4.3 手動補充資料

自動爬取後，您可以手動補充：
- **H 欄（房屋特色）**：填寫物件特色，例如「近捷運、學區宅、車位」
- **K 欄（狀態）**：從下拉選單選擇「上架」、「下架」或「已售出」

## 步驟五：發佈試算表為 CSV

### 5.1 發佈到網路

1. 在試算表中，點擊上方選單：**檔案** → **共用** → **發佈到網路**
2. 在彈出視窗中：
   - **連結**：選擇「整份文件」
   - **格式**：選擇「逗號分隔值 (.csv)」
3. 點擊「發佈」
4. 確認發佈後，複製產生的 CSV 連結，例如：
   ```
   https://docs.google.com/spreadsheets/d/e/2PACX-1vQ.../pub?output=csv
   ```

### 5.2 測試 CSV 連結

1. 將 CSV 連結貼到瀏覽器網址列
2. 應該會下載一個 `.csv` 檔案
3. 用文字編輯器開啟，確認資料格式正確

## 步驟六：使用自訂選單功能

重新整理試算表後，上方會出現「🏠 房地產工具」選單，包含：

### 📋 初始化試算表
- 重新設定標題列與格式
- 適用於需要重置試算表時

### 🔄 手動更新所有經緯度
- 批次更新所有有地址但缺少經緯度的列
- 適用於大量匯入資料後

### 📊 資料統計
- 顯示物件總數、上架數、下架數、已售出數
- 快速了解資料庫狀態

## 常見問題 (FAQ)

### Q1: 爬蟲沒有反應？

**可能原因**：
- 網址格式不正確
- 網站結構已變更
- 網路連線問題

**解決方法**：
1. 確認網址完整且可正常開啟
2. 檢查 Apps Script 的執行記錄（檢視 → 記錄）
3. 如果是網站結構變更，需要更新爬蟲的正則表達式

### Q2: 經緯度沒有自動填入？

**可能原因**：
- 未設定 Google Maps API Key
- API Key 沒有啟用 Geocoding API
- 地址格式不完整

**解決方法**：
1. 確認 API Key 已正確設定
2. 前往 Google Cloud Console 確認 Geocoding API 已啟用
3. 使用「🔄 手動更新所有經緯度」功能批次更新

### Q3: 如何修改已爬取的資料？

直接在試算表中編輯即可。修改後：
- 「最後更新」欄位不會自動更新（除非重新貼網址）
- 如需重新爬取，刪除該列資料後重新貼網址

### Q4: 可以爬取其他網站嗎？

可以！在 `Code.gs` 中新增對應的爬蟲函數，參考現有的 `scrape591()` 等函數結構。

## 進階設定

### 自動觸發器

如果希望定時自動更新資料，可以設定觸發器：

1. 在 Apps Script 編輯器中，點擊左側「觸發器」（時鐘圖示）
2. 點擊右下角「新增觸發器」
3. 設定：
   - 選擇函數：`batchGeocodeAll`
   - 事件來源：時間驅動
   - 時間型觸發條件：每天、特定時間
4. 儲存

### 資料備份

建議定期備份試算表：
1. 檔案 → 建立副本
2. 或使用 Google Takeout 匯出資料
