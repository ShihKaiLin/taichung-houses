# SK-L 大台中地產戰略 - 專案完整說明

## 專案概述

本專案是一個專業的房地產資訊網站，專注於台中市精華區的優質物件。網站採用現代化的技術架構，實現了資料與畫面的完全分離，並提供了完整的自動化資料管理機制。

**網站網址**: https://shihkailin.github.io/taichung-houses/

## 核心功能

### 1. Google Sheets 自動化資料庫

網站資料完全由 Google Sheets 管理，並透過 Google Apps Script (GAS) 實現自動化功能。

**支援的房仲平台**：
- 591 房屋交易網
- 樂屋網
- 永義房屋官網
- 好房網

**自動化功能**：
- **自動爬蟲**：貼上物件網址後，自動抓取案名、地址、價格、圖片等資訊
- **地理編碼**：自動將地址轉換為經緯度座標
- **時間戳記**：自動記錄最後更新時間
- **資料驗證**：確保資料格式正確

**試算表欄位**：
- 網址、案名、行政區、地址、價格（萬元）
- 緯度、經度、房屋特色
- 圖片網址1、圖片網址2、圖片網址3
- 標籤（例如：電梯大樓、出售中）
- 經紀人姓名、聯絡電話、LINE連結
- 最後更新、狀態（上架/下架/已售出）

### 2. 現代化 UI/UX 設計

網站採用 Tailwind CSS 打造，參考 Zillow 和 Airbnb 的設計風格，呈現專業且現代的視覺效果。

**設計特色**：
- **配色方案**：深藍色（主色）+ 森林綠色（強調色）
- **響應式設計**：完美適配桌面、平板、手機
- **動畫效果**：流暢的過渡動畫和 hover 效果
- **視覺層次**：清晰的資訊架構和視覺引導

### 3. Leaflet.js 地圖功能

網站使用 Leaflet.js 搭配 OpenStreetMap，提供穩定且免費的地圖服務。

**地圖功能**：
- **即時標記**：所有物件自動顯示在地圖上
- **互動資訊視窗**：點擊標記可查看物件詳情
- **標記聚類**：多個標記會自動聚類，避免畫面混亂
- **自動調整視野**：地圖會自動調整到包含所有標記的最佳視野

### 4. 物件詳情頁面

每個物件都有專屬的詳情頁面，提供完整的資訊和聯絡方式。

**頁面功能**：
- **圖庫系統**：主圖 + 縮圖列，支援多張圖片展示
- **燈箱效果**：點擊圖片可全螢幕瀏覽（使用 GLightbox）
- **固定聯絡卡片**：桌面版右側固定顯示經紀人資訊
- **手機版固定底部按鈕**：手機版在螢幕底部固定顯示 LINE 和電話按鈕
- **完整物件資訊**：案名、地址、價格、特色、標籤等

### 5. 搜尋與篩選功能

網站提供多種篩選條件，方便使用者快速找到理想物件。

**篩選條件**：
- 行政區（自動從資料中提取）
- 價格區間（1000萬以下、1000-2000萬、2000-3000萬、3000萬以上）
- 關鍵字搜尋（案名、特色、地址）

### 6. SEO 與社群分享優化

網站針對搜尋引擎和社群分享進行了完整優化。

**SEO 優化**：
- **元數據**：優化的 `<title>`、`meta description`、`keywords`
- **結構化資料**：`RealEstateListing` 的 JSON-LD 標籤
- **語義化 HTML**：使用 `<header>`、`<main>`、`<section>`、`<footer>` 等標籤

**社群分享優化**：
- **Open Graph 標籤**：`og:title`、`og:description`、`og:image`
- **動態生成**：每個物件詳情頁面都會動態生成專屬的 OG 標籤
- **預覽效果**：在 Facebook、Threads 等平台分享時，會顯示美觀的預覽卡片

## 使用方式

### 1. 設定 Google Sheets

請參考 `docs/GOOGLE_SHEETS_SETUP.md` 完成 Google Sheets 的設定。

### 2. 新增物件

1. 在 Google Sheets 的第一欄（A 欄）貼上 591、樂屋網、永義房屋或好房網的物件網址
2. GAS 腳本會自動爬取資料並填入相關欄位
3. 網頁會在下次載入時自動顯示新物件

### 3. 修改物件

直接在 Google Sheets 中修改資料即可，網頁會自動更新。

### 4. 下架物件

將物件的「狀態」欄位改為「下架」或「已售出」，該物件將不會顯示在網站上。
